# RE:CIPE

픽셀 아트 테마의 레시피 추천·변형 웹사이트 정적 배포본입니다.

## 실행
`index.html`을 브라우저에서 열거나 GitHub 저장소에 업로드해 GitHub Pages로 배포할 수 있습니다.

## GitHub Pages 배포
1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정해 저장합니다.
4. 잠시 후 표시되는 공개 URL로 접속합니다.

## 현재 구현 범위
- 공통 헤더와 홈/레시피 추천/레시피 변형 메뉴 이동
- 접속 시 홈 카피 무작위 노출 및 RE:CIPE 로고 진입 애니메이션
- CSS로 그린 픽셀풍 토마토·요리 소품과 레트로 UI
- 재료 입력 기반 내장 예시 레시피 매칭
- 레시피 재료 행 추가/삭제, 대체/비율 변경, 변경 결과 비교·복사·인쇄
- 사진 파일 형식 검사 및 첨부 안내 (이미지 OCR/AI 분석은 미연결)

## 아직 연결되지 않은 기능
- 외부 레시피 데이터베이스 및 AI 기반 추천
- 사진 속 글자 인식(OCR) 및 멀티모달 분석
- 식품 과학 데이터 기반의 정밀 배합 최적화와 검증
- 계정, 클라우드 저장, 사용자별 레시피 보관함

변형 결과는 입력값 기반의 계산 및 일반적인 주의 메모이며, 검증된 조리 성공 판정이 아닙니다. API 연동 시 키는 서버 측 환경변수로 관리해야 합니다.
